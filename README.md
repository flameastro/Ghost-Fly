# Ghost Fly

Bem-vindo ao **Ghost Fly**, um jogo feito com muito carinho no **Godot Engine**!

## Download

O executável está disponível na pasta builds:

- Arquivo: Ghost Fly.exe
- Sistema: Windows

## 🛡️ Verificação de integridade

Para garantir que você está jogando exatamente o que foi criado, confira o hash SHA-256 do executável:

`025719CCCCB20CFBC1777B01AC2C394F8A04D3ECAA3EC2DAC3861029F6C5F5EB`

### Como verificar no Windows (PowerShell):

```powershell
Get-FileHash ".\Ghost Fly.exe" -Algorithm SHA256
```

Se o hash for igual ao acima, você está pronto para jogar com segurança!

## ▶️ Como jogar

1. Baixe o arquivo Ghost Fly.exe da pasta builds.
2. Clique duas vezes e divirta-se! Não é necessário instalar nada.
